# Le primarie del centrosinistra

One pager di lavoro per progettare le primarie del centrosinistra, con voto ibrido online e ai seggi a fine gennaio 2027.

- **Pagina**: https://alessandroalberti-researchunit.github.io/primarie-coalizione/
- `index.html`: la pagina, un solo file senza dipendenze oltre ai font.
- `scenari-primarie.md`: studio di supporto con i casi, le fonti e le decisioni prese.

Bozza di lavoro, non è un parere legale. I punti marcati come ipotesi vanno validati con un legale e con i fornitori.
